Esta aplicação é um protótipo acadêmico desenvolvido para demonstrar como tecnologias web podem ajudar a organizar a divulgação de cães e gatos para adoção. Os dados exibidos são fictícios e devem ser substituídos por informações autorizadas antes de qualquer uso real.
